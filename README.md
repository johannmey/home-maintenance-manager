# Home Maintenance Manager

A full-stack home maintenance and asset management platform that helps homeowners track maintenance tasks, repairs, warranties, expenses, and important documents across web and mobile applications.

## Features

- Property management
- Maintenance scheduling
- Recurring reminders
- Warranty tracking
- Asset inventory
- Expense tracking
- Document storage
- Repair history
- Mobile photo uploads
- Dashboard and reporting

## Technology Stack

### Web
- React
- TypeScript
- Tailwind CSS
- Ant Design

### Mobile
- Flutter
- Dart

### Backend
- NestJS
- TypeScript
- PostgreSQL
- Prisma ORM

### DevOps
- Docker
- GitHub Actions
